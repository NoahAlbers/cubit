Backups & recovery

What is saved

Membership and billing databases, uploaded waivers, DocuSeal files, and the configuration needed to recover the service. Backups are encrypted before storage.

Two locations

A local copy helps recover from mistakes. A private off-server copy protects against losing the VPS. A server operator connects storage and keeps the recovery key separately.

Retention

Keep the number of recent successful backups you choose in each location. Cleanup only happens after a new copy has succeeded. Earlier backups made by the old backup system are left alone.

Test recovery

Restore a saved copy into a temporary isolated database, check its tables and waiver files, then remove the test copy. This never replaces the working database. A full replacement-server rehearsal is still needed before launch.
