Billing rules

Grace period

Give members extra time to pay. With 60 days enabled, a member stays eligible through day 60 after their oldest unpaid charge. Access eligibility stops on day 61.

Turn grace off to allow no extra days once a charge is past due. This changes access eligibility; it does not erase charges or end the plan.

Change or undo the rule

You can shorten, extend, or turn grace off at any time. Saving applies the new rule the next time eligibility is checked; you do not need to wait for daily processing. Increasing the window restores eligibility for members now within it. To undo a change, save the previous number of days again.

This only changes billing eligibility. It never edits payments, removes debt, clears a staff access block, or switches individual keys on. A member made inactive with a staff access block stays blocked until staff removes that block.

When a payment arrives

Payments cover the oldest charges first. Eligibility returns when the oldest remaining unpaid charge is within grace, or the account is current when grace is off.

Staff controls still apply

A staff access block and individually disabled keys stay in place. A canceled member needs a new plan. The hosted review never changes physical door access.

Daily processing

When available, daily processing posts due charges and refreshes eligibility. It is paused in hosted demos and imported-data reviews, even when the saved setting is enabled. No emails are sent.

Run processing

Preview first

Preview run shows the charges that would be added and the members whose access eligibility would change. It does not save those changes.

Apply the changes

Run now posts charges due through today and refreshes eligibility using your saved billing rules. An existing charge is not added a second time.

What stays unchanged

Processing does not charge a bank card, collect a PayPal payment, remove a staff block, enable a manually disabled key, or send an email. In a review or demo it only changes that workspace database.

Other balance updates

Opening a profile or recording a payment can also bring that member’s charges up to date. Run history records completed and failed processing attempts.
