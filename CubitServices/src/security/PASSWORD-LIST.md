# Common-password blocklist

`common-passwords.txt` is SecLists' `Passwords/Common-Credentials/10k-most-common.txt`,
retrieved on 2026-09-24 from:
https://github.com/danielmiessler/SecLists/blob/master/Passwords/Common-Credentials/10k-most-common.txt

The supplied MIT license is retained in `SECLISTS-LICENSE.txt`. This is a public
password dictionary, not application credentials or member data. Validation runs
locally; no submitted password is sent to a third-party service.
